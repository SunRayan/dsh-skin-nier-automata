## 三、浅色：设计问题与两个方向

### 核心矛盾

两张人物素材都是**暗场渲染**（黑底、低照度）。放到浅色纸面上只有两条路：

- 保留黑底 → 出现"黑方块"，除非装裱成一张**照片**；
- 压成浅灰 → 变成"脏印子"，除非淡到只当**纹理**。

所以浅色不能照搬深色的"满屏壁纸"，必须换一种**角色定位**。

### 方向 A：水印（两侧都压成铅笔稿）

- 做法：`grayscale(1) brightness(2.05) contrast(.6)` + `mix-blend-mode:multiply` + 径向遮罩。
- 优点：完全不抢文字，整页像一张印刷稿。
- 缺点：人物没有存在感，左边那块容易读成"脏"。

### 方向 B：一卡一印（推荐）

- 右侧留白处放一张**装裱的档案照**（细黑框 + 米白卡纸 + 编号 `YoRHa No.2 Type B · ARCHIVE 02`）；
- 左侧因为全是文字，仍然只放极淡水印（34%）。
- 优点：暗场照片反而成了优点（冲印照片本来就该有黑底），尼尔"档案/报告"的味道直接出来；右侧 gutter 没有文字，不遮挡。
- 缺点：卡片是实体元素，占一块视觉重量；窄屏（<1180px）要隐藏。

### 浅色还欠一件事：token 自相矛盾

现在 light 侧是**暖底 + 冷面板**混搭：

| token | light 值 | 色温 |
|---|---|---|
| `bg-base` | `rgba(237,234,226,.82)` | 暖米 |
| `bg-layer-1` | `rgba(238,241,247,.88)` | 冷白 |
| `bg-layer-2` | `rgba(232,236,243,.9)` | 冷白 |

同一屏里两种白，面板会显得"发蓝"。建议统一到骨白系：`#E9E5DC / #F1EDE4 / #F8F6F0`，边框统一成墨线 `rgba(26,28,31,.14)`。

### 开屏

浅色模式下开屏**保持深色**（系统自检屏），这是刻意的：它是"启动"，不是"文档"。
