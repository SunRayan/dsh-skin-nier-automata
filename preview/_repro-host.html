阅读区：整条链都不透明

这块区域在真实 DSH 里叠了三层底色：.mP3x-q_frame（外层）、 .mP3x-q_centerCol（标题栏模式下）、.an3WzG_root（会话页根节点）。 壁纸层挂在 body 上、z-index:-3，排在 #root 之后绘制—— 所以照片被这一串底色整块盖住，一个像素都露不出来。

同时主题在 body.nier-wp-user 上把城市剪影、地面梯度、天空梯度全部撤掉了， 于是背景变成一片纯色：既没有照片，也没有废墟。

右下角那行 JSON 是实测值：三层都必须是 rgba(0, 0, 0, 0) 照片才算真的透出来。
