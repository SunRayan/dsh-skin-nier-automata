形状语言形状 ≠ 颜色

状态原实现T1-c语义
done 实心圆 实心方 完成＝闭合实体
warning 实心圆 空心方 告警＝有边界、未闭合
error 实心圆 菱形 错误＝越出正交网格
running 蓝色点阵 红色点阵 进行＝扫描中
idle 灰点 横杠 待机＝横杠（静止）
顺带修掉一处配色越界：平台 --dsh-state-ongoing 取 rgb(86,134,254) 青蓝——这是整套 UI 里唯一的青蓝色，直接违反「黑／白／红／冷枪灰」红线。T1-c 把它改绑到 business 红。

将注入的 CSS仅伪元素几何

/* T1-c：只改伪元素几何，盒模型一像素不动。
   平台原规则已给 .dot{position:relative}，伪元素绝对定位被完全约束。 */
body [class*="_dot_"]:before,
body [class*="_dot_"]:after{border-radius:0}

/* done：实心方，60% → 76%，小尺寸才留得住块感 */
body [class*="_dot_"][data-state=done]:after{
  top:12%;right:12%;bottom:12%;left:12%}

/* warning：1px 环，取到 84% */
body [class*="_dot_"][data-state=warning]:before{opacity:.06}
body [class*="_dot_"][data-state=warning]:after{
  top:8%;right:8%;bottom:8%;left:8%;
  background:transparent;border:1px solid currentColor}

/* error：菱形。旋转后包围盒 ×1.41，inset 必须 >=15% 才不溢出 */
body [class*="_dot_"][data-state=error]:after{
  top:15%;right:15%;bottom:15%;left:15%;transform:rotate(45deg)}

/* idle：横杠 —— 刻意不用空心方，避免与 warning 撞形。
   点只有 done/warning/error；无 data-state 才是默认态。 */
body [class*="_dot_"]:not([data-state]):before,
body [class*="_dot_"][data-state=idle]:before{opacity:.05}
body [class*="_dot_"]:not([data-state]):after,
body [class*="_dot_"][data-state=idle]:after{
  top:44%;right:8%;bottom:44%;left:8%;border-radius:0;opacity:.75}

/* running：去掉全 UI 唯一的青蓝 */
body [class*="_matrix_"]{--dsh-state-ongoing:var(--dsw-alias-state-business-primary)}

风险与边界为什么这条最安全

  • 零布局位移：平台已声明 .dot{position:relative}，两个伪元素都是 position:absolute + inset 百分比。只改 border-radius / inset / transform / background，不触碰宽高与 padding，不会推动任何相邻元素。
  • 不新增 DOM：复用平台已存在的 :before（10% 光晕）与 :after（60% 实心），不是叠加新层，所以不存在 z-index 或事件遮挡问题。
  • 无障碍不受影响：该点本身是 aria-hidden，始终与文本标签成对渲染。形状只是视觉辅助，不承担语义。
  • 失败即退化：类名含构建哈希（_dot_10orb_3），平台升级改名后选择器静默失配 → 回到原来的圆点，不报错、不破版。这是 fail-safe 方向。
  • 已知边界：1px 环在 6px 以下会糊成一团，需实测最小尺寸；[class*="_dot_"] 属子串匹配，理论上可能误伤其他含 “_dot_” 的类，实际需在真实 DOM 上核一次命中数量。
